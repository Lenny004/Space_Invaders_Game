Nuestro proyecto hace uso de bases de datos para guardar el Score (Puntaje) del juego y es necesario que se ejecute la base de datos para correr el juego, el nombre de la base de datos es "spaceInvaders" y se encuentra dentro de la carpeta principal, Agregar a las librerias de Java el archivo .jar "sqljdbc42" y con ello se podra ejecutar el juego. Luego en el Package de "ClaseConexion" modificar la Clase "Conexion" en el apartado de "cn = DriverManager.getConnection("jdbc:sqlserver://LENNYX\\SERVIDORSQL; databaseName=spaceInvaders; IntegratedSecurity=true;");" En el apartado que dice "LENNYX" colocar el nombre del Host de su computador y "SERVIDORSQL" por SQLEXPRESS o el servidor que posea su computadora.

Pedimos con respeto que no se utilicen las Imagenes Desarrolladas para el Juego, tienen un costo de tiempo y dedicación, cada una fue desarrollada solo para este Juego y no se debe tomar material de otros como propio ni mucho menos difundirlo sin autorización.

El código por circunstancias de utilización de Base de Datos no ha sido cifrado y puede ser modificado, el código puede ser utilizado como aprendizaje personal para futuros proyectos.
